04 / API INTEGRATION PROJECT

Weather and nearby
bike stations in one view

Developer · API integration

JavaScript Weatherbit CityBikes API

This project combined weather data and bike station information. A user could enter a ZIP code to see local weather alongside nearby bike stations and bike availability.

The need

Weather and bike station information came from separate sources, but could be useful together when planning a trip.

My contribution

Used the entered ZIP code to request weather data, then passed location coordinates into a second API request for nearby bike stations.

What it made possible

A combined response with weather conditions, temperature, sunrise and sunset times, and nearby bike availability.
